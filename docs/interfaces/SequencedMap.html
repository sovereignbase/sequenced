    Interface SequencedMap<K, V>

    A replicated map with native Map-style access and iteration.

    String and numeric keys remain distinct. Keys must be strings or finite numbers. Concurrent duplicate entries resolve to the first entry in projection order. Values retain shallow JavaScript references; use set() to replicate a changed value.
