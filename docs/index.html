    Usage

    import { Sequenced } from '@sovereignbase/sequenced'

    const alice = new Sequenced.Array<string>(1)
    const bob = new Sequenced.Array<string>(2)
    alice.addEventListener('delta', (event) => bob.apply(event.detail))
    alice.push('hello', 'world')
    alice.set(1, 'there')
    console.log([...bob]) // ['hello', 'there']
    alice.destroy()
    bob.destroy()

    API

    Sequenced.Array<T> (also exported as SequencedArray) implements the ES2024 Array instance methods, plus get, set, delete, apply, merge, snapshot, toJSON, typed event listeners and destroy. See the Array API.

    Tests

    SequencedArray equivalence tests run with npm run test:array; check their TypeScript harness with npm run typecheck:array.

    Array benchmarks run with npm run bench:array and compare plain sequencer with the SequencedArray wrapper, including listener overhead. The offline-delivery regression currently fails because of sequencer issue #2.
