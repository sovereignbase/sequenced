    Class SequencedArray<T>

    A dense replicated sequence with the ES2024 Array instance methods.

    Read/write positions use get/set/delete rather than numeric properties. Copying methods return plain arrays; callbacks receive this replica. Values have normal shallow JavaScript reference semantics. Nested object mutations are not replicated: replace the element with set() to publish them.
